# 簡易3Dエンジン

## 作品概要

Siv3DとC++を使用して制作した、
3Dエディタ風の簡易エンジンです。

UnityやUnreal Engineの標準的な3D機能に頼らず、
カメラ制御・オブジェクト操作・衝突判定・ライト計算などを
C++で実装しました。

## 開発環境

- OpenSiv3D：0.6.16
- 使用言語：C++
- Visual Studio 2022
- 開発期間：約3か月
- 開発人数：1人

## 主な実装

### 3Dカメラ

カメラの位置や向きを管理し、
自作したカメラ行列を用いて3D空間を操作できるようにしました。

マウス操作による視点変更にも対応しています。

### Quaternionによる回転制御

オブジェクトの回転処理にQuaternionを使用しました。

オイラー角だけで回転を管理する場合に発生する
ジンバルロックを避けながら、
マウス操作やカメラ方向に応じた回転を実装しています。

### オブジェクト操作

3D空間上のオブジェクトに対して、

- 移動
- 回転
- 拡大・縮小

を行えるようにしました。

3Dエディタのように直感的に操作できることを意識しています。

### 衝突判定・物理処理

オブジェクト同士の衝突判定や
簡単な物理処理をC++で実装しました。

描画処理とは分離して管理することで、
処理内容を整理しやすい構成を意識しています。

### ライト計算

3D空間上のライト情報を使用し、
オブジェクトの見え方へ反映する処理を実装しました。

ライトの位置などを変更しながら、
描画結果を確認できるようにしています。

### 描画順・処理順管理

`std::vector` と
`std::sort` / `std::stable_sort` を使用して、
オブジェクトの描画順や処理順を管理しています。

描画処理と計算処理を分離し、
複数のオブジェクトを扱いやすい構成を目指しました。

## 工夫した点

既存ゲームエンジンの機能を使用するだけではなく、

「3D空間のカメラや回転、衝突判定は
内部でどのように処理されているのか」

を理解することを目的として、
各機能をC++で実装しました。

特にQuaternionによる回転制御では、
3D空間における回転処理について理解を深めることができました。

## ソースコードについて

本リポジトリでは、

実行にはOpenSiv3Dの開発環境が必要です。

## 総括

本制作を通して、
普段ゲームエンジンが内部で行っている
カメラ・座標変換・回転・衝突判定・描画などの処理を
C++で実装する経験を得ました。

特に3D数学やQuaternionへの理解を深め、
ゲームエンジンの内部処理を意識して
